# ООО «БОГДАН» — эффективность оплаты труда

Простое веб-приложение для оценки целесообразности оплаты труда: две вкладки, на каждой — несколько ползунков и один график.
Статический сайт без сборки: HTML + CSS + vanilla JS, графики — Chart.js (cdnjs).

**Опубликованная страница:** https://&lt;user&gt;.github.io/bogdan-labor-efficiency/ <!-- заменить после включения GitHub Pages -->

## Вкладка «Отдача ФОТ» (`#fot`)

Ползунки: выручка, ФОТ, прибыль за период.

| Показатель | Формула |
|---|---|
| Выручка на 1 ₽ ФОТ | Выручка / ФОТ |
| Прибыль на 1 ₽ ФОТ | Прибыль / ФОТ |
| Доля ФОТ в выручке | ФОТ / Выручка × 100 % |

График: обе отдачи при ФОТ от 50 до 150 % текущего. Выручка и прочие расходы считаются неизменными,
поэтому прибыль при другом ФОТ = Прибыль − (ФОТ′ − ФОТ).

## Вкладка «Производительность и зарплата» (`#lead`)

Ползунки: рост выручки, изменение численности, рост средней зарплаты (в %).

| Показатель | Формула |
|---|---|
| Индекс производительности, Iпт | (1 + рост выручки) / (1 + изменение численности) |
| Индекс средней ЗП, Iзп | 1 + рост средней ЗП |
| Коэффициент опережения, К | Iпт / Iзп |
| Допустимое повышение ЗП | Iпт − 1 (максимальный рост ЗП, при котором К ≥ 1) |

Светофор: 🟢 К > 1 · 🟡 0,95 ≤ К ≤ 1 · 🔴 К < 0,95.

График: коэффициент опережения при росте ЗП от −20 до +50 % с порогами 1 и 0,95.

Деление на ноль (ФОТ = 0, выручка = 0) показывается как «—».
