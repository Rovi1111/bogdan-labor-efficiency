# ООО «БОГДАН» — эффективность оплаты труда

Простое веб-приложение для оценки отдачи фонда оплаты труда (ФОТ): три ползунка, три показателя и один график.
Статический сайт без сборки: HTML + CSS + vanilla JS, графики — Chart.js (cdnjs).

**Опубликованная страница:** https://&lt;user&gt;.github.io/bogdan-labor-efficiency/ <!-- заменить после включения GitHub Pages -->

## Показатели

Ползунки: выручка, ФОТ и прибыль за период (млн ₽).

| Показатель | Формула |
|---|---|
| Выручка на 1 ₽ ФОТ | Выручка / ФОТ |
| Прибыль на 1 ₽ ФОТ | Прибыль / ФОТ |
| Доля ФОТ в выручке | ФОТ / Выручка × 100 % |

Если ФОТ или выручка равны 0, соответствующий показатель выводится как «—» с пояснением.
Если прибыль больше, чем выручка минус ФОТ, страница предупреждает о несогласованных значениях.

## График

Обе отдачи при ФОТ от 50 до 150 % текущего значения. Выручка и прочие расходы считаются неизменными,
поэтому прибыль при другом ФОТ = Прибыль − (ФОТ′ − ФОТ). Ромбы — текущие значения.

```

python3 -m http.server 8000
```

Затем откройте http://localhost:8000/.
