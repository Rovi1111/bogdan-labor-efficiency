# ООО «БОГДАН» — эффективность оплаты труда

Одностраничное веб-приложение для экономической оценки целесообразности оплаты труда.
Статический сайт без сборки и бэкенда: HTML + CSS + vanilla JS, графики — Chart.js (cdnjs).

**Опубликованная страница:** https://&lt;user&gt;.github.io/bogdan-labor-efficiency/ <!-- заменить после включения GitHub Pages -->

## Возможности

- Ручной ввод периодов (месяц / квартал / год): выручка, прибыль, ФОТ, численность. Строки можно добавлять и удалять.
- Учёт страховых взносов (по умолчанию 30 %): во всех расчётах используется ФОТ × (1 + ставка).
- Отраслевой ориентир выручки на 1 ₽ ФОТ — пунктирная линия на графике.
- Данные сохраняются в `localStorage` браузера; кнопки «Сбросить к примеру» и «Очистить всё».
- Светлая и тёмная тема (по настройке системы), адаптивная вёрстка.

## Формулы

### Блок 1. Отдача ФОТ

| Показатель | Формула |
|---|---|
| Выручка на 1 ₽ ФОТ | Выручка / ФОТ |
| Прибыль на 1 ₽ ФОТ | Прибыль / ФОТ |
| Доля ФОТ в выручке | ФОТ / Выручка × 100 % |

### Блок 2. Опережение производительности над зарплатой

| Показатель | Формула |
|---|---|
| Производительность труда | Выручка / Численность |
| Средняя ЗП | ФОТ / Численность |
| Индекс производительности, Iпт | Произв.тек / Произв.пред |
| Индекс средней ЗП, Iзп | Ср.ЗП тек / Ср.ЗП пред |
| Коэффициент опережения, К | Iпт / Iзп |

Светофор: 🟢 К > 1 · 🟡 0,95 ≤ К ≤ 1 · 🔴 К < 0,95.

В текстовом выводе «рост ЗП опередил рост производительности на X %» означает X = (Iзп / Iпт − 1) × 100 %.

### Блок 3. Сценарии «что если»

От последнего фактического периода при росте средней ЗП `dW`, изменении численности `dH`, росте выручки `dR` и маржинальности `m`:

```
Численность' = Ч × (1 + dH)
ФОТ'         = СрЗП × (1 + dW) × Ч'
Выручка'     = В × (1 + dR)
Прибыль'     = П + (Выручка' − В) × m − (ФОТ' − ФОТ)      // ФОТ с взносами, если они включены
```

Допустимое повышение средней ЗП (аналитически): поскольку Iпт = (1 + dR) / (1 + dH), а Iзп = 1 + dW,

```
К ≥ 1  ⇔  dW ≤ (1 + dR) / (1 + dH) − 1
```

Ставка страховых взносов на результат не влияет — она сокращается в индексе ЗП.

Если показатель не определён (деление на ноль, нулевая выручка, нет предыдущего периода), выводится «—» с подсказкой о причине.

## Структура

```
index.html        точка входа
css/styles.css    стили (токены цветов, светлая/тёмная тема)
js/calc.js        расчёты — чистые функции (window.Calc)
js/app.js         интерфейс: таблица ввода, графики, сценарии, хранение
.nojekyll         отключает обработку Jekyll на GitHub Pages
```

Расчёты можно проверить в консоли браузера:

```js
Calc.analyze(App.state.rows, App.state.insurance)
Calc.maxWageGrowth(10, 5) // 4,76 % при росте выручки 10 % и численности 5 %
```

## Локальный запуск

```bash
python3 -m http.server 8000
```
